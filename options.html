Spark Study Assistant v0.2.0

Dùng nhiều API kiểu OpenAI Chat Completions, tự sửa endpoint và model, hoặc so sánh đáp án giữa nhiều mô hình. Không có API vẫn dùng bộ quy tắc offline hiện tại.

Chế độ giải bài

So sánh sẽ gọi nhiều API cho mỗi lần giải và có thể phát sinh chi phí ở từng nhà cung cấp. Chỉ tự điền khi ít nhất hai mô hình trả về cùng một đáp án; đáp án bất đồng cần chọn thủ công.

Danh sách cấu hình API

Có thể lưu tối đa 8 cấu hình, gồm OpenAI, OpenRouter, Groq, DeepSeek, Gemini (giao diện OpenAI-compatible), Ollama chạy trên máy hoặc endpoint tự nhập. Tên model và endpoint đều chỉnh được.

Chỉnh sửa cấu hình

Lưu ý: không phải mọi dịch vụ đều tương thích hoàn toàn với OpenAI API. Endpoint này chỉ hỗ trợ dạng POST /chat/completions; API Anthropic native hoặc định dạng khác chưa hỗ trợ.

Riêng tư và giới hạn

Extension chỉ gửi cấu trúc câu hỏi, đáp án lựa chọn đến endpoint bạn đã cấu hình khi bật API. Không gửi cookie, token đăng nhập Spark hoặc URL của trang học. Khóa API nằm trong chrome.storage.local của Chrome, không đồng bộ với GitHub.

Endpoint tùy chỉnh là máy chủ do bạn chọn. Khi dùng, nội dung bài tập và API key của cấu hình đó sẽ được gửi tới máy chủ này. Chỉ sử dụng dịch vụ bạn tin tưởng. Quyền truy cập host được Chrome hỏi khi lưu cấu hình.

Dạng kéo/thả và click sửa lỗi vẫn chưa hỗ trợ tự thao tác đầy đủ; kết quả cần được kiểm tra trước khi nộp bài.
